# みちくさ（Streamlit版）

## ローカルで動かす
```
cd streamlit_app
pip install -r requirements.txt
streamlit run app.py
```
初回起動時にSQLite（`michikusa.db`）が自動作成され、デモ農園（農園ID `C001` / ユーザーID `tanji1234` / パスワード `tanji1234`）と商品・送料表のサンプルデータが投入されます。

## Streamlit Community Cloudへのデプロイ
1. この`streamlit_app`フォルダをGitHubリポジトリにpush
2. https://share.streamlit.io で「New app」→リポジトリ・ブランチ・`app.py`を指定してDeploy

## 実装済みの範囲
- ログイン（bcryptによるパスワードハッシュ化）、マルチ農園（`company_code`で区切り）
- ホーム（表示カードのカスタマイズ対応）
- 注文（複数配送先対応、配送先ごとの配送業者・お届け希望日時、箱サイズ自動判定→送料自動計算、セットアップ完了ゲート、在庫連動）
- 商品管理（箱サイズ必須、取扱休止、削除確認）
- 在庫管理
- 発送管理（配送業者＋追跡番号の両方必須で発送済み化）
- 顧客情報
- 売上明細（期間・顧客名・注文番号での絞り込み）
- 売上分析（客単価、リピーター/新規、売れ筋ランキング、地域別売上）
- 送料設定（運送会社×地域×箱サイズの送料表編集、自動/個別セット切替）
- 領収書設定（テンプレート追加・使用中切替）
- 入金（手数料15%控除、入金済み化、履歴）
- ユーザー管理（削除確認、農園全体ランクへの算入可否、一般権限への機能開示設定）
- 支払方法
- 農園情報編集
- 機能活用ガイド（開示された機能の説明）
- ランクアップ道場（個人/農園全体ランクの進捗バー、レベル別＋苦手問題クイズ、正誤結果と解説、上限付きポイント計算）
- 運営者コンソール（農園アカウント発行・削除・パスワードリセット、利用状況閲覧）

## 未実装・簡略化した部分
- 売上分析のキャンセル率は注文キャンセル機能自体が未実装のため0固定
- 領収書テンプレートは項目の並び替えまでは未対応（表示フラグのみ）
- 運営者ログインはデモ用の固定アカウント（`operator1` / `operator1`）

## 既知の制約
- **SQLiteファイルはStreamlit Community Cloud上で永続保証されません**（再デプロイ・スリープ復帰でリセットされる可能性があります）。検証・デモ用途として割り切るか、商用化時は外部DB（Supabase Postgres等）への切替を推奨します。
- 現状はStreamlitの標準UIコンポーネントのため、HTML版と見た目は異なります。
